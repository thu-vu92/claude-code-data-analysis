# How I Use Claude Code for Data Analysis (Without Exposing My Real Data) ☕

Hey there! 👋 This repo contains all the code, data, and prompts from my YouTube video on doing [**privacy-first data analysis with Claude Code**](https://www.youtube.com/watch?v=IPKOx66fogE).

🎥 **Watch the full video tutorial here:** [https://www.youtube.com/watch?v=IPKOx66fogE](https://www.youtube.com/watch?v=IPKOx66fogE)

If you work with real-world datasets (like customer records, employee data, or financial transactions), you already know you can't just upload your CSV to an AI tool and hope for the best. Even running an AI coding agent locally in your terminal still sends data to the cloud to process your requests.

But here's the thing: **as a data analyst, you don't actually need AI to analyze the data *for* you. You just need it to write solid, working analysis code that you can inspect, run and test yourself.**

---

## 🛠️ How the Workflow Works

In this demo, we pretend we're analyzing 2,000 guest records from a boutique hotel (`hotel_guest_data.csv`), which includes sensitive PII like guest emails, billing addresses, and credit card numbers *(don't worry, the "real" dataset in this repo is 100% fictitious!)*.

Here is the 3-step workflow we use to keep the original data completely out of reach of the AI:

1. **Create a "fake twin" locally (with SDV):**
   Using a Python library called [Synthetic Data Vault (SDV)](https://docs.sdv.dev/), we learn the statistical patterns of our local dataset and generate a 100-row synthetic proxy (`hotel_guest_data_synthetic.csv`). It has the exact same columns, data types, and structure, just with fake emails, addresses, and card numbers.
2. **Let Claude Code do the heavy lifting in the cloud:**
   We open Claude Code in **Cloud mode** (so it has zero access to our local files) and upload *only* the synthetic CSV. Claude writes and tests the exploratory data analysis notebook (`pandas` + `Plotly`) and builds a live preview dashboard against the fake data.
3. **Run the code locally on the real data:**
   We download the notebook and `requirements.txt` to our computer, swap the file path from the synthetic CSV to the real dataset, and run/ test the code locally. Remove, add or change the code to your heart's content 😌.

> 💡 **Pro tip:** Even with synthetic data, only share the minimum columns you actually need to answer your questions. If you don't need credit card numbers for your analysis, drop those columns before uploading!

## 💬 Exact Prompts I Used in Claude Code

In the video, I used **Claude Code on the Cloud** and attached `hotel_guest_data_synthetic.csv`.

### Prompt 1: Build the EDA Notebook & Dashboard
```text
Create a Jupyter notebook to explore this hotel guest data. Use pandas and Plotly (or any other package or library you prefer).

1. Firstly, I want to know how many nights our guests usually stay at our hotel.
2. Secondly, I'm curious what are the most common email domains of our guests.
3. Identify how many regular individual household customers and how many high-volume corporate office accounts we have in our data.

Add code comments to walk the reader through, and mention all the gotchas and data warnings (such as missing values or invalid data). Finally, generate a live dashboard for me to look at the results.
```

### Prompt 2: Grab the `requirements.txt`
When I first ran the downloaded notebook locally, I hit a missing `nbformat` error for rendering Plotly charts, so I asked Claude Code for the exact dependency file:

```text
Please give me a requirements.txt file with the required packages to run this notebook.
```

## 🚀 Try It Yourself

1. **Clone this repo:**
   ```bash
   git clone <your-repo-url>
   cd <your-repo-folder>
   ```

2. **Install the required packages:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Explore the notebooks:**
   - **Synthetic Data Generation Notebook (`sdv`):** Walks through loading the CSV with SDV's `CSVHandler`, auto-detecting table metadata, fixing a misidentified column (`billing_address` detected as `id` instead of `address`), fitting the `GaussianCopulaSynthesizer`, and sampling 100 synthetic rows.
   - **Hotel Guest Analysis Notebook:** The self-contained notebook generated by Claude Code, complete with data quality checks, length-of-stay buckets, email domain breakdowns, and repeat household vs. corporate account analysis. Just point the data path to `hotel_guest_data.csv`, restart your kernel, and run all cells!
